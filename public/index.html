🏃 RunTrack

GPS running tracker — REST API

This server stores runs, GPS routes and per-kilometre splits in Neon PostgreSQL. The mobile app is built with Expo.

MethodPathPurpose
GET/healthuptime + run count
POST/runssave a finished run
GET/runshistory
GET/runs/:idroute + splits
GET/stats/dashboardtotals + streak
GET/stats/chartbar-chart buckets
GET/stats/recordspersonal records
GET/PUT/profileweight → calories
